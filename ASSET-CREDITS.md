# Asset credits and license boundaries

This file records the sources and reuse boundaries for the assets in this repository.

- `public/pfp.png` — portrait supplied by the site owner. It is not included in the MIT source-code license.
- `public/resume.pdf` and `public/resume.html` — personal resume materials supplied by the site owner. They are not included in the MIT source-code license.

Do not copy or redistribute these personal materials without the owner's permission.

## Third-party packages

- **Geist** — font files are provided through the `geist` package. The font remains subject to the license distributed by the upstream package.
- **Phosphor Icons** — icons are imported from `@phosphor-icons/react`. The icon package remains subject to its upstream license.
- **Next.js, React, Tailwind CSS and other packages** — remain subject to the licenses shipped with their respective packages. See the package metadata and lockfile.

This repository does not vendor third-party font files or icon source files outside those packages.

## Original portfolio visuals

The project artwork and Open Graph composition are built in this repository using HTML, CSS and SVG/React markup. They are illustrative compositions created for the portfolio; they are not screenshots of the live Hibbullah product, do not show customer records and should not be presented as production captures.
